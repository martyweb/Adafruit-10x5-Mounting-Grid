# AdaFruit Feather Project and 3D Models

This project is all about learning to create 3d models in [Autodesk Fusion](https://www.autodesk.com/products/fusion-360/personal). I wanted a box that could hold a mounting board and easily support various hardware configurations.

I will adapt my [WaterMyPlants](https://github.com/martyweb/WaterMyPlants) project for this new design.

## Hardware
These are the various components you can mount to the board

1. [Adafruit Swirly Aluminum Mounting Grid](https://www.adafruit.com/product/5774?srsltid=AU7gw4WBiGoXsQHZ5ASNqp4BAxYoQjiEKmPufXs2Fs5CkdjkH8xzrSsB)
2. [Adafruit ESP32-S3 Feather](https://www.adafruit.com/product/5885)
3. [128x64 OLED FeatherWing](https://learn.adafruit.com/adafruit-128x64-oled-featherwing/)
4. [BME680 module](https://learn.adafruit.com/adafruit-bme680-humidity-temperature-barometic-pressure-voc-gas/)
5. [Feather doubler](https://www.adafruit.com/product/2890)
6. [Soil sensor](https://www.adafruit.com/product/4026)
7. [Water pump](https://www.adafruit.com/product/4547)
8. [Battery Guage](https://www.adafruit.com/product/5580)
9. [Stemma Hub](https://www.adafruit.com/product/5625)
10. [DC Motor + Stepper FeatherWing](https://www.adafruit.com/product/2927)
11. [Adafruit I2C Quad Rotary Encoder Breakout with NeoPixelSTEMMA QT / Qwiic](https://www.adafruit.com/product/5752)
12. [Lithium Ion Polymer Battery](https://www.adafruit.com/product/1578)
13. [Nylon Machine Screw and Stand-off Set](https://www.adafruit.com/product/3299?srsltid=AU7gw4V0dh1O2pk5Z3LwJerZ9EeDm7-X-N0sb8d35Yjw108ubVlbFFe_)

## What it does

1. Monitors soil moisture, temp, humidity, pressure, and battery
2. Triggers water pump when dry
3. Displays all info on OLED
